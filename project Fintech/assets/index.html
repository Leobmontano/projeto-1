Crônicas de Péria

Um mundo despedaçado pelos sussurros do Vazio. Você joga como um artesão de ecos que molda memórias em lâminas. Este protótipo reúne criação de personagem, narrativa interativa e uma arena de testes com movimento fluido inspirado em Hollow Knight.

Capítulo zero — O Despertar na Orla de Âmbar

Etapa 1

Forje seu avatar

O código gera sprites vetoriais simples, mas você define o significado. Combine função e emoção para entrar no campo.

O retrato é gerado com formas procedurais — pense como se fosse o primeiro sprite do jogo.

Etapa 2

Campo de provas

Use A/D ou ←/→ para mover, Espaço para pular, Shift para dash e J para atacar. Vença um Eco Sombrio para conquistar sua primeira memória.

Toque para iniciar

O eco do Sino chama você. Pressione qualquer tecla depois de criar seu personagem.

Objetivo

Alcance o alto do penhasco, corte o Eco Sombrio e mantenha-se em movimento. A física é leve e responsiva para que você sinta o ritmo.

    Trama em capítulos

    Enquanto o protótipo se concentra no controle, a linha abaixo sugere a campanha completa.

    1. O Sino Rachado: Péria perde cor, mas um pulso resta no Farol Azul.
    2. A Oficina de Ecos: Você aprende a converter memórias em armas dançantes.
    3. Cidade Suspensa: Plataformas telescópicas revelam segredos dos Antigos.
    4. Gruta das Vozes: Aliados espectrais contam verdades conflitantes.
    5. Convergência: Escolha entre selar o Vazio ou libertá-lo para reinventar o mundo.
    Protótipo criado para demonstrar narrativa, criação de personagem e loop de movimento ágil.
